# Changelog for Player Companions (1.20.1)

## Note

This change log includes the summarized changes.
For the full changelog, please go to the [GitHub History][history] instead.

### 7.0.0 (beta testing)

Note: This is a complete re-write of the Player Companions which uses
the [Easy NPC API][easy_npc_api].
This means existing Player Companions will be lost when updating to this version.
Please make sure to back up your world before updating!

- Added Pig, Rooster and Small Slime companions.
