Player Companions adds companion creatures which can travel with you and support you on your
journey.

## Important for 7.x Users

Player Companions **7.x is a beta version** and a **complete rewrite** of the mod.

Please keep the following in mind before updating:

- **7.x is not compatible with 6.x or older versions.**
- **Older companion data is not guaranteed to work in 7.x.**
- **Existing companions from older versions can be lost after updating.**
- **Always create a full backup of your world before updating.**
- **Do not test beta builds on important saves without a backup.**

## Which Version Should You Use?

### Use 7.x if you want to:

- test the new rewrite
- report bugs and give feedback
- help improve the new foundation
- try the new beta content

### Stay on 6.x if you want:

- the older feature set
- the older companion system
- the more established experience
- to keep an existing long-term world on the old branch

In short: **7.x is the current beta branch, 6.x is the legacy branch.**

## Current State of 7.x

The 7.x branch is intentionally limited right now.
The focus is on rebuilding the technical base first before bringing back more content from older
versions.

### Current beta scope

Currently available in the 7.x beta:

- Pig companion
- Rooster companion
- Small Slime companion

This means that older companion types and older features may still be missing for now.

## Why 7.x Is Different

Version 7.x is not just another update.
It is a new foundation and should be treated like a fresh generation of the mod.
Because of that, old data, old setups, and old expectations from 6.x do not always apply anymore.

## Before You Update

Please do this before installing or updating to 7.x:

1. Create a backup of your world.
2. Create a backup of your server or profile files.
3. Test 7.x in a separate instance first if possible.
4. Only update existing worlds if you are prepared for breaking changes.

For modpacks, servers, and important survival worlds, testing in a separate setup is strongly
recommended.

## Legacy Note for 6.x Users

The older 6.x line may still exist for users who want the previous generation of the mod.
However, the main README is focused on the current 7.x branch to avoid confusion for new users.

If you are still using 6.x, it is best to treat it as a separate legacy branch with its own
expectations and compatibility.

## Beta Means

Because 7.x is still in beta, the following can happen:

- features can be missing
- mechanics can change
- balance can change
- data structures can change
- bugs and regressions can happen between updates

Please always read update notes carefully before moving to a newer beta build.

## Reporting Problems

If you find an issue during beta testing, please include:

- the exact mod version
- the Minecraft version
- the loader you use
- clear reproduction steps
- logs or crash reports if available
- whether it happens in a clean test setup or a modpack

## FAQ

### Can I safely update an old 6.x world to 7.x?

Not safely by default.
You should assume that upgrading can break old companion data.
Always make a backup first.

### Why does 7.x have fewer features right now?

Because the current goal is to rebuild the base properly first.
More content can return later once the rewrite is stable enough.

### Is 7.x ready for normal long-term worlds?

It depends on your risk tolerance.
For stable long-term use, many users should currently stay on the older branch until 7.x matures
further.
